# 紧凑界面与 VirusTotal 查询

用户要求界面接近 OpenHashTab，并确认 API 调用指在软件内配置 VirusTotal API Key。

- 主窗口改为紧凑工具栏、文件名/算法/哈希值列表、底部校验输入与进度。移除侧栏、品牌说明、独立详情面板。算法、主题、导入算法提示和 VT API 配置收进“选项”。
- 保留批量、拖放、取消、复制、导入导出和分页；双击哈希复制哈希，双击名称/算法复制校验行。
- 2026-10-18：默认窗口缩小至 760×500（最小 640×440），默认仅选 MD5。添加路径、导入清单、更改计算算法自动计算；计算中变更配置只保留最新请求，等旧任务和取消确认都完成再启动。手动取消清除排队任务，旧任务晚到事件不能污染新结果；主题和 VT 设置不触发重算。
- VT 网页按钮打开固定的 VirusTotal 文件报告；API 按钮使用用户的 Key 调用 GET `/api/v3/files/{hash}`。仅接受 MD5、SHA-1、SHA-256 文件标识。
- 用户追加要求 Key 本地保存并在重启后自动加载：通过特定 IPC 写入 Windows 凭据管理器 / macOS 钥匙串，启动后自动读取到 Rust 会话；保存后清空输入，不记录日志，不返回密钥。清除操作删除持久凭据。系统存储失败明确报告，不写明文配置；加载期间禁止编辑以避免初始加载覆盖新状态。
- Rust HTTPS 客户端只连接 VT 固定域名，禁用重定向、设置超时和响应大小限制；本地滑动窗口 4 次/60 秒；缓存 10 分钟；远端 429 明确提示额度或频率限制。
- 结果区分已有报告、未收录、尚无分析、认证错误和请求失败；显示检出/引擎数、可疑数量和报告时间，零检出不标注为“安全”。不上传文件，不发起新扫描。
- 使用本地 HTTP 测试服务验证实际请求路径、Key 请求头、状态码和解析；不会使用真实 Key 或把用户文件发送到外网。Windows 生产包重新构建，macOS 仍由配置的 CI 和实机验收确认。

官方接口：https://docs.virustotal.com/reference/file-info

公共 API 当前限制：4 次/分钟、500 次/日，且有非商业及业务工作流限制，详见 https://docs.virustotal.com/reference/public-vs-premium-api 。软件的限流不能替代账户的共享额度或使用条款。
