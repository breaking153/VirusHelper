# VirusHelper 0.1 设计

用户已确认首版为 Windows/macOS 独立文件哈希应用。参考 OpenHashTab 的使用场景，独立实现，不复制其代码或资源。

## 范围

- Rust + Tauri 2 + React + TypeScript，中文界面，明暗主题。
- 最低目标为 Windows 10/11、macOS 12（Intel / Apple Silicon）；前端转译目标包含 Safari 15，避免依赖更高版本的语法或 Array.at。
- 添加多个文件、添加文件夹和原生拖放；递归扫描，去重，跳过目录中的符号链接，报告不可读取的项目。
- MD5、SHA-1、SHA-256、SHA-512、SHA3-256、BLAKE3、CRC32、xxHash64。
- 一次流式读取同时计算所选算法，1 MiB 读取缓冲区；后台任务与界面分离；任务进度和取消；逐文件错误不终止整个批次。
- 文件列表、详情、单项/全部复制、粘贴哈希比对。
- GNU checksum 和 SFV 导入/导出；导入后自动添加清单所需算法。64 位十六进制字符默认 SHA-256，可指定 SHA3-256/BLAKE3；应用导出的清单带算法注释。
- 清单使用相对于清单目录的文件名，不允许绝对路径、父目录跳转或符号链接越界。导出位置必须位于所有源文件的共同上级目录；禁止覆盖本批次源文件。GNU 文件名转义保证含换行/反斜杠名称可往返。
- 所有哈希处理离线；不上传文件，不请求在线服务，不持久化文件路径与哈希。仅存储主题偏好。
- Windows 本地编译验证；GitHub Actions Windows 与 macOS Intel/Apple Silicon 构建、测试、上传构建产物。macOS 实机验证和分发签名不作本地完成声明。

## 结构与契约

- `crates/hash-core`：算法、读取、目录发现、清单解析/序列化、批次任务，完全不依赖 Tauri。
- `src-tauri`：原生选择/保存对话框，任务互斥与取消，Tauri Channel 消息，保存经过后端计算的结果。
- `src`：类型、原生桥接、任务 hook、算法侧栏、文件列表和结果详情。
- 单次仅一个批次任务；开始后锁定输入/算法；取消后保留已经完成结果，未完成文件明确显示已取消。
- Tauri IPC：`pick_files`、`pick_folder`、`pick_manifest`、`run_job`、`cancel_job`、`export_results`、`clear_results`。
- Channel：`discovered`（文件队列）、`progress`（文件与批次字节数）、`file`（最终文件结果）。`run_job` 最终返回总计、错误、校验数量和取消状态。
- 运行时不暴露通用文件读写或 shell 插件；CSP 限制外部内容，原生拖放只监听主窗口。

## 界面

左侧品牌、任务模式和算法选择；主区标题、添加/导入/导出工具栏与文件列表；右侧所选文件的哈希与粘贴校验；底部任务状态和进度。使用中性石墨/浅灰与青绿色强调色。浏览器预览明确提示桌面文件功能不可用，不提供假文件结果。

## 验证

核心库以标准 abc/空文件向量、取消、目录去重、错误路径、清单转义、非法清单和路径越界测试保护。前端验证任务状态、比对逻辑、文件选择后的展示和错误反馈。执行格式检查、Clippy、Rust 测试、TypeScript 检查、前端测试及生产构建。使用浏览器检查真实渲染、键盘操作、窄屏和主题。
